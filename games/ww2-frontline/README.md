项目中的 Three.js 文件保留了原版权标注，模型、贴图和战斗语音等素材还需完成来源核实，详见仓库根目录 `docs/ASSET_PROVENANCE.md`。

## 本地运行

在游戏厅仓库根目录执行 `python -m http.server 8000`，然后打开 `http://localhost:8000/games/ww2-frontline/`。

## 2026-10-10 游戏操作与性能维护

- **移动碰撞**：玩家的 X/Z 分轴移动现在会沿运动路径检查墙体，即使出现较大单帧位移，也不会直接越过薄墙；保留贴墙滑动、地面与台阶的原有行为。
- **切换武器**：Q 和数字键 1–5 仅在新的按键按下时执行一次，忽略长按自动重复事件。
- **渲染像素预算**：在普通 1× 显示器上保留正常原生分辨率，高 DPI 时动态计算内部像素比例，渲染缓冲区目标最多约 260 万像素。原有视角与模型内容不变。
- **F3 调试面板**：按 F3 显示/关闭实际 FPS、WebGL 绘制调用数和内部像素分辨率；统计的是浏览器现场帧率，而非保证的性能指标。
- **雷达绘制**：将小地图 Canvas 的重绘频率限制在约 15 Hz，避免在高刷新率屏幕上随每个 WebGL 帧重复画全部雷达图元。
