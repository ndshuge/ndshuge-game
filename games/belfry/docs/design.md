# 《钟楼契约》BELL & BOND

设计正本 · 2026-09-18 · v1

---

## 0 一句话

> 白天你经营一座农场，夜里你守着它打退从墓穴爬出来的东西。
> 而你每奴役一个怪物当农工，夜色就更凶一分。

中世纪像素 · 昼夜双循环 · **契约经济** roguelite。单局一局 14 天，一天约 6 分钟，整局 60 到 90 分钟。

---

## 1 三个坐标（鼠哥点的题，逐条咬合）

| 坐标 | 借什么 | 不借什么 |
| --- | --- | --- |
| **元气骑士** | 俯视角动作手感：挥砍的弧、命中顿帧、击退、震屏、可读的敌人预警 | 不借它的房间-关卡结构（那是另一套骨架，会跟农场打架） |
| **星露谷物语** | 昼夜节奏、地块耕作、作物生长、镇民、天数推进 | 不借它的"无压力"基调，这里的白天是有代价的 |
| **像素风** | 16×16 tile、粗描边、高对比轮廓、暖农场 / 冷墓穴的双色域对冲 | 不借星露谷那种柔和低对比，战斗时需要一眼读懂 |

## 2 核心创新：契约（Bond）

这是整个游戏唯一必须成立的东西。别的都可以砍，这个不能。

**规则**：夜里击败敌人时，你二选一。

| 选择 | 收益 | 代价 |
| --- | --- | --- |
| **斩杀 Rend** | 当场得魂火（货币 + 锻造材料） | 无 |
| **缚契 Bind** | 它变成农场劳工，从此白天替你耕地、浇水、收割、夜里替你打 | **业火 Ward 永久 +1**，夜晚强度立即上一个台阶 |

**业火（Ward）**是全局压强，不是滑条，是资产负债表：

```
夜晚强度倍率   = 1 + ward × 0.18
刷新速率倍率   = 1 + ward × 0.12
BOSS 提前天数  = floor(ward / 3)
契约者上限     = 2 + 建筑升级(0..3)
```

**契约者会磨损（Wear）**：每个契约者每天掉活力，活力归零就**叛变**，白天在你的农场里变成敌人。

```
vigor -= wear        # 每天结算
vigor <= 0  ->  叛变，在农场内随机位置生成为敌对单位
魂火喂养    ->  vigor 恢复
```

**双重消耗**：契约者夜间替你作战也会掉活力。所以"让它们打仗"和"让它们干活"在抢同一份活力池。

### 为什么这条设计成立

三个循环不再是并排的两套皮，而是**互为因果**：

1. 想省白天的手 → 得多缚契 → 业火涨 → 夜里更难 → 需要更好的武器
2. 想要好武器 → 得下墓穴取材料 → 又要花夜里那点时间
3. 契约者替你打夜战 → 活力掉得快 → 白天的活没人干 → 又得缚更多契

玩家每天都在解同一个方程：**今天的魂火投给武器，还是投给劳工？** 没有正确答案，只有取舍，而且取舍会复利。

## 3 昼夜循环

| 阶段 | 时长 | 内容 | 压力来源 |
| --- | --- | --- | --- |
| **晨 Dawn** | 20s | 结算昨日、喂养契约者、看今日预言（预告今晚敌人构成） | 无 |
| **昼 Day** | 150s | 农活、锻造、镇民交易与对话、修建筑 | 体力条 |
| **昏 Dusk** | 25s | 钟声倒计时，布置守卫位、给契约者分配夜战/休息 | 时间 |
| **夜 Night** | 150s | 俯视角波次防守，墓穴裂口涌怪 | 命 + 业火 |
| **结 Settle** | 15s | 战果、魂火、契约者活力、剧情推进 | 无 |

固定步长主循环，昼夜按真实秒推进，倒计时在 HUD 上明示。

## 4 系统清单

### 4.1 农场

- 地块状态机：`荒 → 已开垦 → 已播种 → 生长(0/1/2) → 成熟 → 已收割`
- 作物 5 种，昼夜推进生长（夜里的潮湿会额外推一格，契约者浇水也推一格）

| 作物 | 生长 | 用途 |
| --- | --- | --- |
| 灰麦 Ashwheat | 2 天 | 魂火基础产出 |
| 烛莲 Candlelotus | 3 天 | 恢复契约者活力 |
| 铁蕨 Ironfern | 3 天 | 锻造材料 |
| 月葡 Moongrape | 4 天 | 换镇民好感 / 稀有交易 |
| 悼铃草 Knellgrass | 5 天 | 降低业火 1 点（稀缺资源，全游戏最贵的作物） |

### 4.2 锻造

- 3 档武器 × 2 分支：**钟锤系**（近战，重击 + 击退）／**圣烛系**（远程，穿透 + 灼烧）
- 材料来自铁蕨 + 墓穴掉落。武器只影响夜战，不介入白天。

### 4.3 敌人（4 种 + 2 BOSS，行为互相区分）

| 敌人 | 行为 |
| --- | --- |
| **骸仆 Thrall** | 稳定追踪，成群，血薄 |
| **坟蝠 Gravewing** | 绕行俯冲，进入距离后瞬时加速，撞墙眩晕 |
| **墓守 Cairn** | 高血高撞，半血狂暴，死后分裂两只骸仆 |
| **哀鸣者 Wailer** | 站桩吟唱，给周围敌人加攻速；必须先点掉 |
| **BOSS · 钟灵回声**（day 7） | 鸣钟震屏 + 召唤三只哀鸣者 |
| **BOSS · 最初的契约者**（day 14） | 复刻玩家当前武器，反制你的 build |

### 4.4 镇民与剧情

3 个镇民，好感度影响交易折扣与情报（情报 = 预告今晚敌人构成，价值很高）。

剧情 5 幕，绑定天数：`day 1 / 3 / 6 / 9 / 12`。

### 4.5 三结局（第 14 天结算）

| 结局 | 条件 | 内容 |
| --- | --- | --- |
| **熄钟 Silence** | 魂火足够（≥ 阈值） | 摧毁古钟，瘴雾吞镇，所有契约者重获自由。你的农场没了，它们活了 |
| **承钟 Vigil** | 缚契数 ≥ 5 | 把契约者的魂献给钟灵，小镇永续，契约者湮灭 |
| **空钟 Hollow** | 全程缚契数 = 0 | 最难路径。钟灵醒了，一口魂都没吃到，自行散尽。真结局 |

结局不是按键选出来的，是**你前 13 天的行为攒出来的**。

## 5 技术方案

**复用 LUMEN SIEGE 已验的底座**，只换内容层：

| 复用 | 来源 |
| --- | --- |
| 字符矩阵 → 离屏 canvas 编译（含受击闪白变体） | `pixel-game/src/sprites.js` |
| Web Audio 零资源合成音效 | `pixel-game/src/audio.js` |
| 固定步长主循环 + 整数倍缩放 | `pixel-game/src/main.js` |
| 无头测试骨架（最小 DOM/canvas stub，真执行全脚本） | `pixel-game/tests/` |
| `file://` 契约：经典 script 标签、零外部资源 | 同上 |

| 新写 | 说明 |
| --- | --- |
| 昼夜状态机 | 本项目的心脏 |
| 农场地块系统 | 地块网格 + 生长推进 + 契约者 AI 工作分配 |
| 契约系统 | 缚契 / 磨损 / 业火 / 叛变 |
| 双武器手感层 | 近战挥砍弧 + 远程穿透 |
| 剧情与对话 | 5 幕 + 镇民 |
| 农场/墓穴双色域渲染 | 白天暖调、夜里冷调 + 灯笼光锥 |

- 逻辑分辨率 **640×360**（16:9），窗口整数倍放大，`imageSmoothingEnabled = false`
- 零依赖、零构建、双击 `index.html` 即玩
- 存档 `localStorage`：最高天数、结局解锁、音效设置
