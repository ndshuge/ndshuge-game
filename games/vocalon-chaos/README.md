# VOCALON! 节拍革命

[在线游戏](https://ndshuge.github.io/ndshuge-game/games/vocalon-chaos/) · [游戏厅](https://ndshuge.github.io/ndshuge-game/)

## 性能调整（2026-10-10）

原来的单个 `index.html` 内嵌了三首音频的 Base64 数据，文件约 12.77 MB。现在音频分离为 `audio/track-0.m4a`、`track-1.m4a`、`track-2.m4a`，只有选中歌曲后才通过网络获取，已经解码的音频和谱面继续使用原有内存缓存。

| 指标 | 原版 | 调整后 |
| --- | ---: | ---: |
| 首页 HTML 大小（未压缩） | 12,766,039 B | 约 73 KB |
| 打开选歌页时加载三首音频 | 是，随 HTML 一起下载 | 否，按所选歌曲下载 |
| 原曲文件字节 | 内嵌 Base64 | **未重新编码，SHA256 与原音频一致** |
| 离线 / 下载失败时的音乐 | 原有合成音乐回退 | 保留原有 8-bit 合成音乐回退 |

三份原始 M4A 总计 9,333,076 字节。以上为源文件大小对比，**不是**对所有设备网络速度、帧率或实际节省流量的承诺。

在本地 Windows Chrome 和 HTTP 服务下，三首歌曲均经过真实浏览器选择、下载、WebAudio 解码、自动谱面生成与倒计时测试。另修复了倒计时负时间导致背景轨道绘制出现负半径的错误。

## 本地启动

改为独立音频文件后，应使用 HTTP 服务启动，**不要直接双击 `index.html` 以 `file://` 地址加载**。可在游戏厅仓库根目录执行：

```sh
python -m http.server 8000
```

然后打开 `http://localhost:8000/games/vocalon-chaos/`。

## 校验

```sh
node games/vocalon-chaos/tests/audio-assets.test.cjs
```
