# LUMEN SIEGE / 光核围城

一个俯视角像素动作生存小游戏。你是废墟里唯一还亮着的光，蚀影从四面合围，
撑得越久它们越强。单局 5 到 10 分钟。

**双击 `index.html` 即可游玩。** 不需要服务器、不需要构建、不需要网络。

---

## 操作

| 输入 | 动作 |
| --- | --- |
| `WASD` / 方向键 | 移动 |
| 鼠标 | 瞄准 |
| 鼠标左键（按住） | 攻击 |
| `空格` | 冲刺（短暂无敌） |
| `P` / `Esc` | 暂停 |
| `1` `2` `3` | 升级时快速选择 |

## 玩法

击杀蚀影掉经验，经验满级会暂停游戏并给出**强化选择**。强化池有 **51 项**，分三个稀有度：

| 稀有度 | 含义 | 例子 |
| --- | --- | --- |
| 普通 | 稳定的数值成长 | 光刃强化、疾行、光核扩张、自愈 |
| 稀有 | 增加一种新行为 | 分裂光、贯穿、追踪光、手里剑、轰爆、元素灼烧、荆棘、弹射 |
| 传说 | 改变这一局的打法 | 链式闪电、光盾、印记、狂暴、不屈、幸运、回旋镖、灯灵哨卫、引力井、处决 |

稀有度权重随等级倾斜：**局越长，抽到稀有与传说的概率越高**。所以开局是慢慢搭架子，
后期是连续质变。

### 副武器

除了鼠标那盏灯，还有五套自己干活的武器，各有自己的升级线：

| 武器 | 形态 |
| --- | --- |
| **环绕手里剑** | 贴着你转的环，1 到 8 枚，接触即伤害 |
| **回旋镖** | 自动投出，去程回程各打一次，最多同时 5 枚 |
| **灯灵哨卫** | 跟着你的自动炮台，自己找最近敌人点射 |
| **引力井** | 周期性在脚下开一个场，把敌人扳进去并持续磨碎 |
| **分裂弹** | 光弹命中后向四周炸出一圈碎片 |

另外两个不造物的骑手效果：**处决**（残血直接斩）、**缓流**（命中减速）。

武器之间会撞出完全不同的 build：手里剑 + 磨刃 + 旋刃是贴身绞肉机，
分裂光 + 贯穿 + 链式闪电是满屏弹链，回旋镖 + 快镖 + 连抛是远程扫地机。

### 上手引导

第一次进入游戏会先放五段剧情，同时把操作教完（瞄准、移动、冲刺、拾取、升级）。
引导看过一次就不再拦路；开始界面的「重看剧情引导」可以随时重放。

### 敌人

三种蚀影的行为机制不同，不是换皮：

| 敌人 | 行为 |
| --- | --- |
| **爬蚀 Crawler** | 稳定追踪，带蛇形摆动，数量最多 |
| **迅蚀 Zipper** | 直线逼近，进入射程后停身蓄力发光，再沿锁定方向扑击；撞墙会眩晕 |
| **重蚀 Bulwark** | 装甲厚、转向迟缓，半血后进入狂暴加速 |

### 难度

难度按生存时间分 12 档递增：刷新更快、同屏上限更高、敌人血量与伤害更厚，
第 2 档解锁迅蚀，第 4 档解锁重蚀。**敌人的经验值也随档位一起涨**，
所以后期不会出现「敌越厚、升越慢」的双重收紧。

### 地图

1600x1200 像素的世界，约为 3.3 x 4.4 个屏幕。四象限各有自己的地面配色与装饰
（冷石 / 苔藓 / 干土 / 腐化），有随机石簇障碍、地标石柱与实心边界，相机平滑跟随。

## 技术

- HTML5 + CSS + 原生 JavaScript + Canvas 2D。零依赖，零构建。
- **所有像素图形都是代码画出来的**：角色与敌人用字符矩阵定义后编译成离屏 canvas，
  地面在开局一次性烘焙，全部走最近邻放大（`imageSmoothingEnabled = false`）。
- **所有音效都是 Web Audio API 现场合成的**，打击音是四层叠出来的：瞬态 click + 噪声 body
  + 正弦 thump + 方波 crack。连杀时击杀音会沿五声音阶逐级爬升，HUD 上同步显示 `COMBO`；
  低血量会开始心跳。HUD 上的 `SND ON/OFF` 可随时关闭，设置会持久化。
- 逻辑分辨率固定 480x270，按窗口大小取整数倍放大保证像素锐利；窗口装不下整数倍时退回小数缩放，
  避免把 HUD 裁出屏幕。
- 经典 `<script>` 标签加载，不使用 ES module，因此 `file://` 下双击即可运行。
- 进度存 `localStorage`：最长生存时间、最高等级、最多击杀、音效设置。

> 说明：`fetch` / `XMLHttpRequest` / 外部图片都不存在，游戏完全离线自洽。

## 文件结构

```
index.html          外壳：canvas + HUD + 四个界面
style.css           全部样式（像素风 UI、HUD、升级卡片）
src/core.js         常量、数学、种子随机、粒子系统、localStorage 封装
src/input.js        键鼠输入与每帧按键边沿
src/audio.js        Web Audio 合成音效
src/sprites.js      像素矩阵 -> 离屏 canvas（含受击闪白变体）
src/map.js          世界生成、地面烘焙、tile 碰撞、区域配色
src/combat.js       光弹、命中检测、经验宝石
src/player.js       移动、瞄准、冲刺、射击、受伤、成长
src/enemies.js      三种敌人与各自的行为状态机
src/upgrades.js     39 种强化、三级稀有度、随等级倾斜的加权抽取
src/ui.js           HUD、界面切换、升级卡片
src/intro.js        开场剧情引导（兼教程，只跑一次）
src/game.js         单局生命周期、刷新与难度曲线、相机、震屏、渲染编排
src/main.js         启动、缩放、固定步长主循环
tests/smoke.test.mjs 结构验收（25 项，无依赖）
tests/headless.test.mjs 无头集成（18 项，真实执行）
tests/run-all.mjs  统一验收入口
```

## 验证

```bash
node tests/run-all.mjs
```

两个套件，任一失败即非零退出：

| 套件 | 断言 | 证明什么 |
| --- | --- | --- |
| `tests/smoke.test.mjs` | 30 项 | 结构：脚本依赖顺序、每个源文件能否解析、是否守住 `file://` 契约（无 ES module、无远程资源）、核心系统是否存在、新机制与副武器是否真的实现、每个强化是否指向玩家真有的字段、音效是否分层 |
| `tests/headless.test.mjs` | 18 项 | 运行时：在最小 DOM/canvas stub 里**真实执行**全部 13 个脚本并驱动帧循环，验证输入→移动→射击→击杀→升级→死亡→重开整条链，以及 120 秒无人值守运行的稳定性 |

无头套件的环境刻意不含网络、模块加载器与 Web Audio，与 `file://` 的约束同构；
拿不到的浏览器 API 都不 stub，游戏必须优雅降级。渲染是 stub 的，所以它**补充**浏览器实机
验证，而不替代。

无头套件曾抓到一次真实的测试脆弱性：dash 用例把玩家推出了地图中心的无障碍区，
随机生成的石块就会挡住弹道。修法是把用例钉在中心开火（生成器保证中心五格内无石头），
不是放宽断言。

调试钩子：页面暴露 `window.__LUMEN__`（游戏实例）与 `window.__LUMEN_ERRORS`（加载期错误），
供自动化游玩测试读取实时状态。

## 设计取向

- 攻击要有反馈：命中闪白、击退、火花粒子、震屏、音效，五件事同时发生。
- 冲刺要有重量：残影、地面粒子、短暂无敌、明确的冷却读数。
- 敌人要能读懂：迅蚀蓄力时发光预警，重蚀头顶有血条，出生时地面炸开一圈尘土。
- 死亡要让人想再来一局：结算突出生存时间与击杀数，破纪录时高亮提示。
