# 游戏厅素材来源核验

该仓库收录 15 款独立浏览器游戏。**对整仓库直接加一个 MIT 或其他开源许可证之前，应先核查每款游戏的音乐、配音、字体、图片和第三方依赖。**

## 优先检查项

| 目录/文件 | 原因 | 状态 |
| --- | --- | --- |
| `games/ww2-frontline/three.min.js` 和 `models/OBJLoader.js` | 包含第三方 Three.js 渲染与模型加载代码 | 需确认上游许可证、版本及保留声明 |
| `games/ww2-frontline/models/` | 模型、贴图和战斗语音 MP3 | 未验证分发与商用权限 |
| `games/vocalon-chaos/index.html` | 单文件体积约 12.8 MB，内含大量音频相关内容 | 需检查原曲、采样、编码资源以及可公开分发权 |
| `games/belfry/assets/*.png` | 地图/场景图像 | 需明确原创、委托创作或第三方授权 |
| `games/lumen-siege/` | 代码生成的像素艺术与音效系统 | 仍应核实是否复用了外部素材及依赖 |

## 统一登记格式

每项资源应登记：**文件路径 / 作者 / 来源 URL / 版本 / 许可证 / 可再分发范围 / 证据或说明**。

可以先为经核实的原创源码单独选择开源许可证，并在 README 中明确哪些目录和素材不适用该许可证。未核实之前不应宣传所有游戏资源均可自由复用或商用。

本清单不会改变任何现有素材或游戏行为。
